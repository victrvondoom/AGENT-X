Offline Certificate Verifier

Save this page and open it from your own disk, with your network off if you like. It re-derives the certificate hash and checks the ECDSA P-256 signature in your browser. Nothing is sent anywhere, and no server is asked for an opinion.

What is being checked. The hash is recomputed over the canonical JSON of the certificate object — sorted keys, separators (',',':'), UTF-8, no whitespace — and compared to the sha256 field. The signature is verified against the public_key embedded in the certificate itself, so a forged certificate would have to be signed by a key it also carries, and you can compare that key against one published independently.

What this cannot tell you. Whether the live audit chain in the database still matches. That needs the database, and the SQL to check it yourself is in the README — it does not go through the application either.
