The problem

Deleting a row does not delete the memory.

Agent memory sprawls: raw documents, an extracted knowledge graph, and vector embeddings that each hold a copy of the same fact. Drop the row and the embedding still answers. Drop the embedding and the MVCC history, the backups, and the object store still hold the bytes. Ghost Vectors (2026) reconstructs 25.5% of exact names from precisely this residue.
